## Key Conceptual Differences

### Static vs Dynamic Typing

**Python** (Dynamic):
```python
def process_user(user):
    return user.name.upper()  # Runtime error if user.name is None
```

**Boba** (Static):
```boba
fn process_user(user: User): string {
    return user.name.to_upper()  // Compiler ensures user.name exists
}
```

### Immutability by Default

**Python** (Mutable):
```python
def update_scores(scores, new_score):
    scores.append(new_score)  # Modifies original list
    return scores
```

**Boba** (Immutable):
```boba
fn update_scores(scores: int[], new_score: int): int[] {
    return [...scores, new_score]  // Creates new list
}
```

## Step 3: Converting Classes to Structs

**Python**:
```python
class BankAccount:
    def __init__(self, account_number, initial_balance=0.0):
        self.account_number = account_number
        self.balance = initial_balance
        self.transaction_history = []
    
    def deposit(self, amount):
        if amount <= 0:
            raise ValueError("Deposit amount must be positive")
        self.balance += amount
        self.transaction_history.append(f"Deposited ${amount}")
        return self.balance
    
    def withdraw(self, amount):
        if amount <= 0:
            raise ValueError("Withdrawal amount must be positive")
        if amount > self.balance:
            raise ValueError("Insufficient funds")
        self.balance -= amount
        self.transaction_history.append(f"Withdrew ${amount}")
        return self.balance
```

**Boba**:
```boba
struct BankAccount {
    account_number: string,
    balance: float,
    transaction_history: string[]
}

impl BankAccount {
    fn new(account_number: string, initial_balance: float = 0.0): BankAccount {
        return BankAccount {
            account_number: account_number,
            balance: initial_balance,
            transaction_history: []
        }
    }
    
    fn deposit(amount: float): Result<BankAccount, string> {
        if amount <= 0.0 {
            return Err("Deposit amount must be positive")
        }
        
        let new_balance = self.balance + amount
        let transaction = f"Deposited ${amount}"
        
        return Ok(BankAccount {
            ...self,
            balance: new_balance,
            transaction_history: [...self.transaction_history, transaction]
        })
    }
    
    fn withdraw(amount: float): Result<BankAccount, string> {
        if amount <= 0.0 {
            return Err("Withdrawal amount must be positive")
        }
        if amount > self.balance {
            return Err("Insufficient funds")
        }
        
        let new_balance = self.balance - amount
        let transaction = f"Withdrew ${amount}"
        
        return Ok(BankAccount {
            ...self,
            balance: new_balance,
            transaction_history: [...self.transaction_history, transaction]
        })
    }
}
```

**Boba**:

## Step 5: File and I/O Operations

```python
import os

def load_config(filename):

        return None

            return json.load(f)
    except (IOError, json.JSONDecodeError) as e:
        print(f"Error loading config: {e}")
        return None

def save_data(data, filename):
    try:
        with open(filename, 'w') as f:
            json.dump(data, f, indent=2)
        return True
    except IOError as e:
        print(f"Error saving data: {e}")
        return False
```

**Boba**:
```boba
import std:fs
import std:json

fn load_config(filename: string): Option<Config> {
    if !fs.exists(filename) {
        return None
    }
    
    let content = fs.read(filename).ok()?
    let config = json.parse<Config>(content).ok()?
    return Some(config)
}

fn save_data(data: Data, filename: string): Result<(), string> {
    let json_string = json.stringify(data)
    fs.write(path: filename, content: json_string)
}
```

**Boba**:

### List Processing

**Python**:
```python
def process_users(users):
    active_users = [u for u in users if u.active]
    emails = [u.email for u in active_users if u.email]
```

**Boba**:
```boba
fn process_users(users: User[]): string[] {
    return users
        .filter(|u| u.active)
        .filter_map(|u| u.email)  // Only keep Some(email) values
        .unique()                 // Remove duplicates
        .collect()
}
```

## Step 8: Performance Considerations

### Python Global Interpreter Lock (GIL)

**Python** (Limited parallelism):
```python
import threading

def process_data_parallel(data_chunks):
    threads = []
    for chunk in data_chunks:
        thread = threading.Thread(target=process_chunk, args=(chunk,))
        threads.append(thread)
        thread.start()
    
    for thread in threads:
        thread.join()
```

**Boba** (True parallelism):
```boba
import std:async

async fn process_data_parallel(data_chunks: DataChunk[]): Result<(), string> {
    let futures = data_chunks.map(|chunk| async {
        process_chunk(chunk).await
    })
    
    let results = futures.await_all().await?
    return Ok(())
}
```

## Step 10: Migration Strategy

### Gradual Migration Approach

1. **Start with utilities**: Convert small, self-contained functions first
2. **Convert data structures**: Migrate classes to structs
3. **Add type annotations**: Make implicit types explicit
4. **Handle errors explicitly**: Replace exceptions with Result types
5. **Embrace immutability**: Refactor mutating operations
6. **Add comprehensive tests**: Use Boba's built-in testing

### Python Compatibility Mindset Shifts

- **Dynamic → Static**: Embrace compile-time error detection
- **Mutable → Immutable**: Think in terms of data transformation
- **Exceptions → Results**: Make error handling explicit
- **Duck typing → Strong typing**: Let the compiler help you
- **Runtime checking → Compile-time guarantees**: Trust the type system

The migration from Python to Boba rewards you with increased safety, better performance, and more maintainable code!
