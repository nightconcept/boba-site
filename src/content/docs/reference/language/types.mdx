## Primitive Types

### `int`
64-bit signed integer type.

**Range**: -9,223,372,036,854,775,808 to 9,223,372,036,854,775,807

**Literal Syntax**:
```boba
42
-17
1_000_000  // Underscores for readability
0x1A2B     // Hexadecimal
0o755      // Octal
0b1010     // Binary
```

**Methods**:
- `to_string(): string` - Convert to string representation
- `abs(): int` - Absolute value
- `checked_add(other: int): Option<int>` - Addition with overflow checking
- `checked_mul(other: int): Option<int>` - Multiplication with overflow checking
- `saturating_add(other: int): int` - Addition that saturates at bounds
- `wrapping_add(other: int): int` - Addition with wrapping on overflow

### `float`
64-bit double-precision floating-point number (IEEE 754).

**Literal Syntax**:
```boba
3.14
-0.5
1.23e-4   // Scientific notation
2.0       // Always include decimal point
```

**Special Values**:
- `float.INFINITY` - Positive infinity
- `float.NEG_INFINITY` - Negative infinity  
- `float.NAN` - Not a Number

**Methods**:
- `to_string(): string` - Convert to string
- `to_int(): int` - Truncate to integer
- `round(): float` - Round to nearest integer
- `floor(): float` - Round down
- `ceil(): float` - Round up
- `abs(): float` - Absolute value
- `is_finite(): boolean` - Check if finite
- `is_nan(): boolean` - Check if NaN

### `string`
UTF-8 encoded text string.

**Literal Syntax**:
```boba
"hello"
"multi\nline"
r"raw string with \n literal backslashes"
f"interpolated string with {variable}"
```

**Escape Sequences**:
- `\n` - Newline
- `\r` - Carriage return
- `\t` - Tab
- `\\` - Backslash
- `\"` - Quote
- `\{` - Literal brace in f-strings
- `\u{1F4A9}` - Unicode code point

**Methods**:
- `len(): int` - Length in characters
- `is_empty(): boolean` - Check if empty
- `contains(substr: string): boolean` - Check if contains substring
- `starts_with(prefix: string): boolean` - Check prefix
- `ends_with(suffix: string): boolean` - Check suffix
- `split(delimiter: string): string[]` - Split into array
- `trim(): string` - Remove leading/trailing whitespace
- `to_upper(): string` - Convert to uppercase
- `to_lower(): string` - Convert to lowercase
- `replace(from: string, to: string): string` - Replace all occurrences
- `substring(start: int, end: int): string` - Extract substring
- `chars(): char[]` - Convert to character array

### `boolean`
Logical true/false value.

**Literal Syntax**:
```boba
true
false
```

**Methods**:
- `to_string(): string` - Convert to "true" or "false"

### `char`
Single Unicode character.

**Literal Syntax**:
```boba

'🦀'
'\n'
'\u{1F4A9}'
```

## Collection Types

### Arrays: `T[]`
Ordered, homogeneous collection with dynamic size.

**Syntax**:
```boba
let numbers: int[] = [1, 2, 3]
let empty: string[] = []
```

**Methods**:
- `len(): int` - Number of elements
- `is_empty(): boolean` - Check if empty
- `push(item: T): T[]` - Add element to end (returns new array)
- `pop(): Option<(T, T[])>` - Remove last element
- `get(index: int): Option<T>` - Safe element access
- `first(): Option<T>` - First element
- `last(): Option<T>` - Last element
- `contains(item: T): boolean` - Check if contains element
- `map<U>(f: fn(T) -> U): U[]` - Transform elements
- `filter(f: fn(T) -> boolean): T[]` - Filter elements
- `fold<U>(init: U, f: fn(U, T) -> U): U` - Reduce array
- `sort(): T[]` - Sort elements (requires Ord trait)
- `reverse(): T[]` - Reverse order
- `slice(start: int, end: int): T[]` - Extract subarray
- `join(separator: string): string` - Join to string (T must be string)

### Maps: `[K:V]`
Key-value associations with unique keys.

**Syntax**:
```boba
let scores: [string:int] = {"alice": 100, "bob": 85}
let empty: [int:string] = {}
```

**Methods**:
- `len(): int` - Number of key-value pairs
- `is_empty(): boolean` - Check if empty
- `contains_key(key: K): boolean` - Check if key exists
- `get(key: K): Option<V>` - Get value by key
- `insert(key: K, value: V): [K:V]` - Add/update key-value pair
- `remove(key: K): [K:V]` - Remove key-value pair
- `keys(): K[]` - All keys as array
- `values(): V[]` - All values as array
- `entries(): (K, V)[]` - All key-value pairs

## Option and Result Types

### `Option<T>`
Represents a value that may or may not exist.

```boba
enum Option<T> {
    Some(T),
    None
}
```

**Methods**:
- `is_some(): boolean` - Check if has value
- `is_none(): boolean` - Check if empty
- `unwrap(): T` - Extract value (panics if None)
- `unwrap_or(default: T): T` - Extract value or return default
- `unwrap_or_else(f: fn() -> T): T` - Extract value or compute default
- `map<U>(f: fn(T) -> U): Option<U>` - Transform contained value
- `filter(f: fn(T) -> boolean): Option<T>` - Filter based on predicate
- `and_then<U>(f: fn(T) -> Option<U>): Option<U>` - Chain operations
- `or(other: Option<T>): Option<T>` - Return self if Some, else other
- `ok_or<E>(error: E): Result<T, E>` - Convert to Result

### `Result<T, E>`
Represents either success with a value or failure with an error.

```boba
enum Result<T, E> {
    Ok(T),
    Err(E)
}
```

**Methods**:
- `is_ok(): boolean` - Check if success
- `is_err(): boolean` - Check if error
- `unwrap(): T` - Extract value (panics if Err)
- `unwrap_err(): E` - Extract error (panics if Ok)
- `unwrap_or(default: T): T` - Extract value or return default
- `expect(message: string): T` - Extract value or panic with message
- `map<U>(f: fn(T) -> U): Result<U, E>` - Transform success value
- `map_err<F>(f: fn(E) -> F): Result<T, F>` - Transform error value
- `and_then<U>(f: fn(T) -> Result<U, E>): Result<U, E>` - Chain operations
- `or(other: Result<T, E>): Result<T, E>` - Return self if Ok, else other
- `ok(): Option<T>` - Convert to Option, discarding error

## User-Defined Types

### Structs
Group related data together.

```boba
struct Point {
    x: float,
    y: float
}

struct User {
    id: int,
    name: string,
    email: Option<string>
}
```

### Enums
Define types that can be one of several variants.

```boba
enum Color {
    Red,
    Green,
    Blue,
    RGB(int, int, int),
    Named(string)
}

enum Result<T, E> {
    Ok(T),
    Err(E)
}
```

### Generics
Types parameterized by other types.

```boba
struct Container<T> {
    value: T
}

enum Either<L, R> {
    Left(L),
    Right(R)
}

fn identity<T>(x: T): T {
    return x
}
```
