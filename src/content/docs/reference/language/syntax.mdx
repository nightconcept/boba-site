### Operator Precedence
From highest to lowest precedence:

1. Function calls, field access, indexing: `()` `.` `[]`
2. Unary operators: `!` `-` `+` `*` `&`
3. Multiplicative: `*` `/` `%`
4. Additive: `+` `-`
5. Shift: `<<` `>>`
6. Bitwise AND: `&`
7. Bitwise XOR: `^`
8. Bitwise OR: `|`
9. Comparison: `==` `!=` `<` `<=` `>` `>=`
10. Logical AND: `&&`
11. Logical OR: `||`
12. Range: `..` `..=`
13. Assignment: `=` `+=` `-=` etc.
