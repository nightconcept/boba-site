## Overview

The `std:fs` module provides functions for file system operations including reading, writing, and querying files and directories.

import std:fs

## File Reading

### `read(path: string): Result<string, string>`

Read the entire contents of a file as a UTF-8 string.

**Parameters:**
- `path` - Path to the file to read

**Returns:**
- `Ok(content)` - File contents as string
- `Err(message)` - Error message if operation fails

**Example:**
```boba
import std:fs

let content = fs.read("config.txt")
match content {
    Ok(text) => print(f"File contains: {text}"),
    Err(error) => print(f"Error reading file: {error}")
}
```

### `read_bytes(path: string): Result<byte[], string>`

Read the entire contents of a file as raw bytes.

**Parameters:**
- `path` - Path to the file to read

**Returns:**
- `Ok(bytes)` - File contents as byte array
- `Err(message)` - Error message if operation fails

**Example:**
```boba
let data = fs.read_bytes("image.png")
match data {
    Ok(bytes) => print(f"Read {bytes.len()} bytes"),
    Err(error) => print(f"Error: {error}")
}
```

### `read_lines(path: string): Result<string[], string>`

Read a file and split it into lines.

**Parameters:**
- `path` - Path to the file to read

**Returns:**
- `Ok(lines)` - Array of lines (without newline characters)
- `Err(message)` - Error message if operation fails

**Example:**
```boba
let lines = fs.read_lines("data.txt")
match lines {
    Ok(line_array) => {
        for (index, line) in line_array.enumerate() {
            print(f"Line {index + 1}: {line}")
        }
    },
    Err(error) => print(f"Error: {error}")
}
```

## Error Handling

Common error conditions include:

- **File not found**: Attempting to read a non-existent file
- **Permission denied**: Insufficient permissions to access a file
- **Directory not empty**: Trying to remove a non-empty directory with `remove_dir`
- **Disk full**: No space available for write operations
- **Invalid path**: Malformed or invalid file paths

Always handle errors appropriately using pattern matching on `Result` types.
