## Parsing JSON

### `parse<T>(json_string: string): Result<T, string>`

Parse a JSON string into a Boba value of the specified type.

**Type Parameters:**
- `T` - The target type to parse into

**Parameters:**
- `json_string` - JSON string to parse

**Returns:**
- `Ok(value)` - Parsed value of type T
- `Err(message)` - Error message if parsing fails

**Example:**
```boba
import std:json

struct User {
    id: int,
    name: string,
    email: string,
    active: boolean
}

let json_text = r#"{"id": 1, "name": "Alice", "email": "alice@example.com", "active": true}"#
let user = json.parse<User>(json_text)

match user {
    Ok(u) => print(f"User: {u.name} ({u.email})"),
    Err(error) => print(f"Parse error: {error}")
}
```

### `parse_array<T>(json_string: string): Result<T[], string>`

Parse a JSON array into a Boba array of the specified type.

**Type Parameters:**
- `T` - The element type of the target array

**Parameters:**
- `json_string` - JSON array string to parse

**Returns:**
- `Ok(array)` - Parsed array of type T[]
- `Err(message)` - Error message if parsing fails

**Example:**
```boba
let json_array = r#"[{"id": 1, "name": "Alice"}, {"id": 2, "name": "Bob"}]"#
let users = json.parse_array<User>(json_array)

match users {
    Ok(user_list) => {
        for user in user_list {
            print(f"User {user.id}: {user.name}")
        }
    },
    Err(error) => print(f"Parse error: {error}")
}
```

### `parse_value(json_string: string): Result<JsonValue, string>`

Parse JSON into a dynamic value type that can represent any JSON structure.

**Parameters:**
- `json_string` - JSON string to parse

**Returns:**
- `Ok(value)` - Parsed JSON value
- `Err(message)` - Error message if parsing fails

**Example:**
```boba
enum JsonValue {
    Null,
    Bool(boolean),
    Number(float),
    String(string),
    Array(JsonValue[]),
    Object([string:JsonValue])
}

let json_text = r#"{"users": [{"name": "Alice"}, {"name": "Bob"}], "count": 2}"#
let value = json.parse_value(json_text)

match value {
    Ok(JsonValue.Object(obj)) => {
        if let Some(JsonValue.Number(count)) = obj.get("count") {
            print(f"Found {count} users")
        }
    },
    Err(error) => print(f"Parse error: {error}")
}
```

## Serializing to JSON

### `stringify<T>(value: T): string`

Convert a Boba value to its JSON string representation.

**Type Parameters:**
- `T` - Type of the value to serialize

**Parameters:**
- `value` - Value to convert to JSON

**Returns:**
- JSON string representation

**Example:**
```boba
let user = User {
    id: 1,
    name: "Alice",
    email: "alice@example.com", 
    active: true
}

let json_string = json.stringify(user)
print(json_string)
// Output: {"id":1,"name":"Alice","email":"alice@example.com","active":true}
```

## Working with Optional Fields

### Handling Missing Fields

When parsing JSON, optional fields should be represented using `Option<T>`:

```boba
struct UserProfile {
    id: int,
    name: string,
    email: Option<string>,        // May be null or missing
    phone: Option<string>,        // May be null or missing
    age: Option<int>,             // May be null or missing
    settings: Option<UserSettings> // Nested optional object
}

struct UserSettings {
    theme: string,
    notifications: boolean
}

let json_minimal = r#"{"id": 1, "name": "Alice"}"#
let json_complete = r#"{
    "id": 1, 
    "name": "Alice", 
    "email": "alice@example.com",
    "age": 30,
    "settings": {"theme": "dark", "notifications": true}
}"#

// Both will parse successfully
let user1 = json.parse<UserProfile>(json_minimal)?
let user2 = json.parse<UserProfile>(json_complete)?

// Access optional fields safely
match user2.email {
    Some(email) => print(f"Email: {email}"),
    None => print("No email provided")
}
```

## Error Handling

### Common Parse Errors

JSON parsing can fail for several reasons:

```boba
enum JsonError {
    SyntaxError(string),      // Invalid JSON syntax
    TypeError(string),        // Type mismatch 
    MissingField(string),     // Required field missing
    InvalidValue(string)      // Value doesn't match constraints
}

fn safe_json_parse<T>(json_string: string): Result<T, JsonError> {
    json.parse<T>(json_string).map_err(|error| {
        if error.contains("syntax") {
            JsonError.SyntaxError(error)
        } else if error.contains("type") {
            JsonError.TypeError(error)
        } else if error.contains("missing") {
            JsonError.MissingField(error)
        } else {
            JsonError.InvalidValue(error)
        }
    })
}
```
